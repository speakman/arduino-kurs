Kom igång efter kursen

Pedagogiskt strukturerade resurser för att fortsätta lära dig på egen hand.

Paul McWhorter — Arduino Lessons

Hundra+ videolektioner i mycket lugnt tempo. Bygger upp koncepten stegvis — perfekt för vuxen självinlärning.

Den enda Arduino-resursen som verkligen undervisar istället för att snabb-genomgå projekt.

toptechboy.com/arduino-lessons/
Programming Electronics Academy

Förklarar varför Arduino-koden funkar som den gör. Pedagogiskt komplement till McWhorter, mer fokus på koncept än hands-on.

programmingelectronics.com
DroneBot Workshop

Långa djupgångar (30–60 min/video) i specifika ämnen — sensorer, motorer, displayer och kommunikationsmoduler som funkar direkt på din UNO R3. Aktiv och uppdaterad 2026.

dronebotworkshop.com
Arduino IDE 2.x — officiell guide

Hur du installerar, konfigurerar och felsöker Arduino IDE 2.3.8 (versionen som kom feb 2026).

Många "Arduino-tutorials" på nätet är fortfarande skrivna för gamla IDE 1.x — den ser annorlunda ut.

docs.arduino.cc/software/ide/

Slå upp medan du kodar

När du sitter mitt i en sketch och behöver veta hur en funktion fungerar — eller söker svar på en specifik bugg.

Arduino Language Reference

Komplett funktionsreferens med kodexempel för varje API. digitalWrite, analogRead, Serial.print, alla operatorer, alla datatyper.

Du kommer slå upp den dagligen när du kodar. Bookmarka.

docs.arduino.cc/language-reference/
Arduino Documentation Hub

Centrala officiella dokumentationen — täcker UNO R3, UNO R4, Cloud, IDE 2.x. Aktivt uppdaterad 2026.

docs.arduino.cc
Arduino Forum (officiellt)

Discourse-forum för konkreta felsökningsfrågor. Posta din kod och en bild av kopplingen för snabbast svar.

forum.arduino.cc
Arduino Stack Exchange

Strikt Q&A-format. Ofta bättre än forum för specifika tekniska frågor — sökbart för andra med samma problem.

arduino.stackexchange.com
r/arduino (Reddit)

Aktivt subreddit. Snabbast svar på enkla nybörjarfrågor om du postar kod + foto av wiring.

reddit.com/r/arduino
Svenska ElektronikForumet

Enda svenska forumet med kritisk massa. Svar på svenska om du föredrar det. Verifierat aktivt 2026.

elektronikforumet.com/forum/

Hitta nästa projekt

Inspirationsbankar med tusentals projekt — sortera efter komponenter du redan har eller efter komplexitetsnivå.

Arduino Project Hub

Officiell community-katalog med 6 100+ projekt. Filtrera på UNO för att se bara vad du kan bygga med kortet du har.

Kvaliteten varierar — välj projekt med många vyer och kommentarer.

projecthub.arduino.cc
Adafruit Learning System

3 300+ tutorials med extremt hög standard. Den kvalitet andra tutorial-sajter jämförs mot.

learn.adafruit.com
ELEGOO Tutorials

Officiella tutorials från företaget som tillverkade just ditt kit. Använd som referens när du vill plocka upp en komponent från lådan du inte använt än.

elegoo.com/blogs/arduino-projects
Hackster.io

Bredare maker-community än bara Arduino. Bra för att se vad andra bygger med kombinationer av Arduino + 3D-print + ML + andra plattformar.

hackster.io
Random Nerd Tutorials

Mycket aktivt 2026. Topp-3 när du googlar "ESP32 + någon sensor" — när du har växt ur UNO och börjar med WiFi-kort.

randomnerdtutorials.com
SparkFun Learn

Hookup Guides per komponent — när du behöver kalibrera en specifik sensor eller modul du köpt.

learn.sparkfun.com

Bredda ditt kit

Du behöver inte byta hårdvara för att bygga mer ambitiösa projekt — bara fler komponenter. Här är det självklara nästa steget för någon med ELEGOO Basic Starter Kit.

ELEGOO 37-in-1 Sensor Module Kit

37 olika sensor- och utgångsmoduler i en låda — DHT11 temperatursensor, IR-mottagare + fjärrkontroll, joystick, relä, vibrationssensor, ljudsensor, hall-givare, reed-switch, LCD1602, mer. Cirka 300 kr på Amazon.se.

Direkt påbyggnad av Basic Starter Kit:et — samma UNO, samma Arduino IDE, samma C-kod. Bara helt nya sensor-typer att läsa av och fler utgångar att styra. Mycket projekt-värde per krona.

amazon.se · ELEGOO 37-in-1 Sensor Kit

När du har växt ur UNO

Naturliga uppgraderingar — mer prestanda, WiFi, eller riktig C++.

ESP32 (DOIT DEVKIT V1 eller ESP32-S3 Feather)

240 MHz, WiFi + Bluetooth, ca 100–200 kr. Det självklara steget när du vill att Arduinon ska prata med nätet. Programmeras i Arduino IDE 2.x.

Större marknad och fler tutorials än UNO R4 WiFi, billigare per kort.

developer.espressif.com — getting started 2026
Raspberry Pi Pico 2 W

RP2350, WiFi/Bluetooth, ca 50 kr. Mer kraft än UNO, programmeras i Arduino IDE via earlephilhower/arduino-pico-tillägget. Bästa "behåll Arduino-känslan men få mer prestanda".

raspberrypi.com/products/raspberry-pi-pico-2/
Arduino UNO R4 WiFi

Officiell sequence-uppgradering inom Arduino-ekosystemet. WiFi, mer minne, samma form factor och pinnar som UNO R3. Electrokit har den för 299 kr.

arduino.cc/UNOR4WiFi
PlatformIO (VSCode-extension)

Naturlig steg-upp från Arduino IDE. Riktig debugger, multi-platform-stöd (Arduino + ESP32 + Pico + STM32 från samma editor), library-management och unit tests.

platformio.org
Wokwi (Arduino-simulator i webbläsaren)

Simulera Arduino-kretsar utan hårdvara. Gratis för personligt bruk. När du vill testa en idé på lunchen utan att packa upp kittet.

Begränsning: 3,3V/IOREF/AREF/RESET-pins ej tillgängliga i UNO-simuleringen, custom libraries kräver Pro-plan.

wokwi.com
learncpp.com — modern C++

De-facto standard för att lära sig C++ ordentligt. Gratis, stegvis, täcker C++11/14/17/20/23. Bästa resursen efter Arduino-basics när du vill ta steget till "riktig" C++.

learncpp.com
DigiKey: "The Basics of C++ on an Arduino" (5 delar)

Mest direkta brygga från "Arduino C-stil" till "Detta är faktiskt C++". Perfekt mellanlandning innan learncpp.com.

digikey.com/en/maker/tutorials/2020

Bra bibliotek att utforska

När du tar nästa steg utöver det som kommer med Arduino IDE som standard.

Adafruit NeoPixel

Standardvalet för WS2812B-LED-strips — adresserbara LED-remsor där varje pixel kan ha sin egen färg. En datapinne räcker för hundratals LED:er.

github.com/adafruit/Adafruit_NeoPixel
FastLED

När du vill bygga något ambitiöst med många LED:er — animationer, gradienter, palette-effekter. #2 mest populära Arduino-biblioteket totalt.

fastled.io
OneWire + DallasTemperature

För DS18B20-temperatursensorer (de små vattentäta i metallhylsa). Mycket vanligt val för "övervaka kylskåp / akvarium / växthus".

github.com/PaulStoffregen/OneWire
Arduino Libraries-katalogen

De-facto centralregister över 8 000+ bibliotek. Visar senaste uppdatering — bra för att se om ett bibliotek är aktivt underhållet.

arduinolibraries.info
