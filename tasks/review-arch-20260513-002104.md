## Strengths

**Module isolation is clean at the directory boundary.** `docs/` sits next to `presentation/` and `kompendium/` as a peer. Nothing reaches into `docs/`. Only inbound coupling is `presentation/package.json:9`.

**Asset directory is self-contained.** Every internal href is relative or `/arduino-kurs/`-prefixed and the slides build uses `--base /arduino-kurs/slides/`.

**Decision against Actions is reasonable for this scale.** Pages from `/docs` on `main` is simplest reproducible path.

**Design tokens DID get re-declared, not hard-coded.** Intent to share an abstraction is visible.

**Plan-to-execution scope discipline is strong.** Every commit corresponds to a numbered task.

## Issues

### Critical (must fix)

**C1. `docs/nedladdningar.html:60,87,124,157` — malformed `<thead>` tags break four tables**

`<th scope="col"ead>` appears at all four `<thead>` opening sites. Search-replace pass clobbered the head tag. On the most-trafficked utility page, the markup wrapping the entire data set is broken. Also signals automated cleanup pass that wasn't re-validated.

**Fix:** Replace `<th scope="col"ead>` with `<thead>`. Then `git grep 'scope="col"ead'` for residual.

**C2. Slidev build output committed to `docs/slides/` — no documented refresh contract**

- `presentation/dist/` → gitignored, transient
- `docs/slides/` → committed, ~25 MB

Every `slides.md` edit makes `docs/slides/` stale until someone runs `npm run build:pages`. No pre-commit hook, no CI check, no mention in CLAUDE.md's "Verifierings-pipeline", no mention in any README. Tribal knowledge.

Kompendium solved sister problem correctly with `bash build.sh`. New system has no equivalent.

**Fix:** Add documentation (`docs/REFRESH.md` or CLAUDE.md section), refresh script (`docs/refresh.sh` or `npm run refresh:docs`), and add docs/ to Verifierings-pipeline.

### Important (should fix)

**I1. `docs/assets/css/site.css:7-37` — design-token drift from `presentation/styles/main.css:18-47`**

| Token | presentation | docs |
|-------|-------------|------|
| `--ak-text-mute` | `#8a95a3` | `#5b6577` |
| `--ak-accent-soft` | same ✓ | same ✓ |
| `--ak-warn` | same ✓ | same ✓ |

Plan committed to "Designsystem återanvänder samma tokens". Implementation diverged. WCAG AA tuning in presentation won't propagate.

**Fix (minimum):** Add comment block at top of `docs/assets/css/site.css` flagging sync requirement. Add to CLAUDE.md DO/DON'T table.

**I2. `docs/dag/{1,2,3,4,5}.html` — five files repeat 80+ lines of chrome**

Each dag page has lines 1-54 + final ~50 lines structurally identical. Plan endorsed duplication, but consequence is real: footer changes are 5-place edits; all 5 dag pages have the *same bug* (I3) because duplication compounded one bad copy.

**Fix options:** Template script (`tools/build-dag.sh`), Jekyll `_includes` (Pages supports it free), or accept and document in CLAUDE.md.

**I3. All five dag pages mark "Träffarna" with `href="1.html" class="active"`** — duplicates of code-quality I7. Same fix.

**I4. Asset duplication is undocumented and unbounded**

- PDFs: 15 in kompendium/deliveries + 16 in docs/assets/pdf = ~94 MB
- Images: PNG originals AND WebP derivatives both committed in docs/assets/img/ — PNGs unused (every HTML uses `.webp`)
- Slides build: presentation/dist gitignored, docs/slides committed

**Fix:**
1. Delete `.png` originals in `docs/assets/img/` (dead bytes).
2. Document refresh contract.
3. Consider size-budget assertions for future bloat.

**I5. `presentation/package.json:9` — `build:pages` writes outside presentation tree, no breadcrumb**

First cross-subsystem mutation. No breadcrumb from `docs/` back to "this folder is regenerated by `cd presentation && npm run build:pages`".

**Fix:** Add `docs/slides/REGENERATED-FROM.md` one-liner.

**I6. `docs/slides/_redirects` exists — Pages doesn't read it**

Slidev emits a Netlify/Cloudflare Pages convention file. Harmless cruft, but suggests no one looked at what was being committed.
