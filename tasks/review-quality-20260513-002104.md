## Issues

### Critical (must fix)

#### 1. `docs/nedladdningar.html:60, 87, 124, 157` — corrupted `<thead>` tags break table semantics on all four tables

Every `<thead>` opening tag is malformed: `<th scope="col"ead>` instead of `<thead>`. The HTML parser will interpret this as a `<th>` cell with a bogus `ead=""` attribute. Each table will have a stray empty `<th>` injected, and the closing `</thead>` will be orphaned. Lighthouse a11y 100 is misleading because `scope="col"` on real `<th>` still works — but the structure is semantically broken.

**Fix:** Change all four occurrences of `<th scope="col"ead>` to `<thead>`.

#### 2. `docs/dag/1.html:144` — broken link to `bilaga-f-framspanningsfall.pdf`

The page links to `../assets/pdf/bilaga-f-framspanningsfall.pdf`. That file does not exist — only `bilaga-d-hackathon-losning.pdf` is shipped standalone; F lives inside `bilagor-a-f.pdf`.

**Fix:** Repoint the link to `bilagor-a-f.pdf`.

#### 3. `docs/dag/4.html:210` — prose contradicts the embedded code about tilt-sensor logic

Prose: *"Står sensorn rätt upp ligger bollen mot två stift och sluter kretsen → digitalRead ger LOW (med INPUT_PULLUP). Lutar du sensorn rullar bollen iväg → kretsen bryts → HIGH."*
Code comment: `// HIGH = upprätt, LOW = lutad`
Slides + `.ino` agree with the COMMENT (HIGH=upprätt). Prose is wrong.

**Fix:** Edit prose to match: upright = ball away → HIGH; tilted = ball touches → LOW.

### Important (should fix)

#### 4. `docs/nedladdningar.html` PDF rows — "Ladda ner ↓" labels don't actually download

All PDF links lack the `download` attribute. They open inline in browser PDF viewer. The `.ino` links DO use `download`. Inconsistent + counter to user-intent ("Nedladdningar").

**Fix:** Add `download` to every `<a class="dl-link" href="assets/pdf/...">`.

#### 5. `docs/assets/code/larm-komplett.ino:53` — misleading "debounce" comment

`delay(50); // debounce tilt — kulan bouncar i hylsan` — this is not debouncing, just a blocking delay. Students will misunderstand what debouncing actually is.

**Fix:** Change comment to: `// ge tilt-bollen 50 ms att sluta studsa innan vi använder värdet`.

#### 6. `docs/assets/code/larm-komplett.ino:66` — typo "RÖRT" → should be "LUTAD"

The comment `// LARM AKTIVT + RÖRT → tjut + rött blink` uses neuter "Rört" which doesn't agree; should match the variable name `tiltLutad` used 3 lines below.

**Fix:** `// LARM AKTIVT + LUTAD → tjut + rött blink`.

#### 7. `docs/dag/{2,3,4,5}.html:35` — nav "Träffarna" has `class="active"` but href points elsewhere

From dag/3, the active link in nav says "Träffarna" and clicking it jumps to dag/1. Inconsistent semantic.

**Fix:** Remove `class="active"` on dag-pages so active state isn't misleading; OR build `dag/index.html` as real hub.

#### 8. `docs/dag/1.html:257` and equivalents — `hljs.highlightAll()` called unguarded

If `highlight.min.js` fails to load, `hljs` is undefined and the script throws ReferenceError.

**Fix:** `<script>if (window.hljs) hljs.highlightAll();</script>`
